🪶Overview

Floater is a lightweight JavaScript library for creating elegant modal popups. Easily display dialogs, alerts, or custom content without complex setup. (Source code available on GitHub)

Getting Started

ZIP

If you prefer not to use npm or CDN links, you can manually install Floater by downloading the library files directly. This option is ideal when you want full control over the source files, or if your project doesn’t rely on a build system.

Get the most recent version of Floater from the official repository or website: 👉 Download Floater.zip

After downloading, unzip the archive into your project’s directory. See a folder structure similar to this: 

/your-project/
├── index.html
├── js/
│   └── floater.min.js
└── css/
    └── floater.min.css

Add the JavaScript and CSS files to your HTML so that the library can be loaded on page load: 

<head>
    <link rel="stylesheet" href="./css/floater.min.css">
    <script src="./js/floater.min.js"></script>
</head>

Via CDN

If you don’t want to download or install anything locally, you can use Floater directly from a CDN. This is the fastest and easiest way to get started — just copy and paste a few lines into your HTML file.

Add the stylesheet inside your index.html file: 

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/anya-phan/floater@v1.0.1/floater.min.css">
<script src="https://cdn.jsdelivr.net/gh/anya-phan/floater@v1.0.1/floater.min.js"></script>

Initialization

This script creates a new instance of Floater and get the value of <content> to make the content for the modal. When the .open() method is called, show the modal. 

// Initialize a new modal
const modal = new Floater({
    content: '<h1>This is content</h1>',
    // template: 'modal',
    footer: true,
    destroyOnClose: false,
    closeMethods: ['overlay', 'button', 'escape'],
    cssClass: ['class-1', 'class-2'],
    onOpen: function() {
        console.log('Modal opened');
    },
    onClose: function() {
        console.log('Modal closed');
    },
});

// Set modal content
modal.setModalContent('<h1>This is new content</h1>');

// Add footer buttons
modal.addFooterBtn('Cancel', 'cancel-btn modal-btn', function(e) {
    modal.close();
});

modal.addFooterBtn('Submit', 'submit-btn modal-btn', function(e) {
    modal.close();
});

// Open the modal
modal.open();

// Close the modal
modal.close();

If you want to get content from an available <template>, don't specify content. The template contains ID-string of HTML <template> tag that its content will appear inside the modal window. Floater automatically reads and renders this content when .open() is called. 

<template id="modal"> 
  <p>
    Content Modal: Lorem ipsum dolor sit amet consectetur adipisicing elit. 
    Quibusdam accusamus veritatis ullam quae laudantium.
  </p>
</template>

Parameters

Parameter Type Default Description
content string | HTMLElement HTML content inside the modal
template string ID of template that contains the content of modal. If the content parameter was specified, template was be ignored
cssClass array [] Adding CSS classes to the modal container
Example: 
cssClass: ['class-1', 'class-2']
closeMethods array ['button', 'overlay', 'escape'] List of modal closing methods
destroyOnClose boolean true Set to false if you want to remain the modal in DOM when it's closed
lockScroll boolean true Set to false if you want modal to have footer
footer boolean false Set to true if you want modal to have footer
onOpen function undefined Callback function executed when the modal opens
onClose function undefined Callback function executed when the modal closes

Methods

Method Description
open() Opens the modal and triggers the onOpen callback.
close() Opens the modal and triggers the onOpen callback. If close(true) is called, it behaves the same as destroy(), removing the modal from the DOM.
setModalContent() Updates the modal content.
setFooterContent() Updates the footer content.
Only working if parameter footer: true
addFooterButton() Adds a button to the footer with a callback function.
Only working if parameter footer: true
destroy() Completely removes the modal elements from the DOM and unbinds all associated events.

Styling

Customize Floater modals with your own CSS or override default variables. 

.floater__backdrop {
    position: fixed;
    inset: 0;
    display: flex;
    align-items: center;
    justify-content: center;
    background: rgba(0, 0, 0, 0.6);
    visibility: hidden;
    opacity: 0;
    transition: visibility, opacity;
    transition-duration: 0.3s;
    transition-timing-function: ease-in-out;
}

Customize Floater modals with your own CSS or override default variables.

Class Description
.floater__backdrop Styles the backdrop overlay for the modal. Handles positioning, centering the modal, and applying a semi-transparent background.
.floater__container Styles the modal container, including its size, padding, border-radius, and transform animations for scaling in/out.
.floater__close Styles the close button inside the modal, including its size, position, and hover effects.
.floater__content Handles the modal's main content area, including scrollable behavior with a maximum height.
.floater__footer Styles the modal footer, aligning buttons to the right and adding spacing between them.
.floater--show Applied when the modal is visible. Controls the visibility and opacity of the backdrop.
.floater--no-scroll Disables scrolling when the modal is open.

You can view the full CSS file directly here: floater.css
